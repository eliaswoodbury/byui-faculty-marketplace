# BYU–Idaho Faculty Pilot marketplace

This repository groups the faculty pilot plugins under one marketplace catalog while keeping each plugin independently installable.

The supported Codex marketplace manifest is at `.agents/plugins/marketplace.json`. Select this repository root when adding the local marketplace.

## Included

- **BYU-Idaho Essay Grader** — local v0.1.2 plugin with its existing Essay-grader MCP connection preserved.
- **Plugin Compliance Reviewer** — reviews plugin source and packages against the university IT safety and governance baseline.
- **Faculty Canvas Messaging Educator** — teaches safe Canvas audience selection and individual messaging using fictional data only.

All three plugins are complete local packages in `plugins/`.
